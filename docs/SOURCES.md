# SOURCES.md — 교역자 청빙 수집 소스 카탈로그

> **검증 이력**: ① 전국 수집 → ② 냉정 재검증(2026-07-12) → ③ 실측 재검증(2026-07-21, 14 에이전트) → ④ Fable 교차감사(2026-07-21) → ⑤ **운영자 전수 실측·크롤 대상 확정(2026-07-27)**. **살아있는 문서** — 활동성·URL은 수시로 바뀌니 크롤 착수 전 각 소스 재확인.
>
> ⚠️ **로그인 티어**: 인증 크롤은 공개 페이지와 법적 결이 다름(약관·정보통신망법) → **실행 전 변호사 확인 게이트** + 계정은 운영자 제공.
>
> ⚠️ **커버리지**: "공식 게시판만" 정책은 실제 청빙 물량의 **일부만** 커버(교단별 편차 큼 — §5). 통합·고신은 신학교 게시판이 부교역자 1차 창구라 커버율이 높지만, 합동·감리·순복음·침례는 상업 채널 비중이 큼.
>
> ⚠️ **포함 기준(2026-07-21 결정)**: 교단은 게시판이 아니라 **공고에서 확정**(CONTRACT §2)하므로, 소스 채택 기준은 "무슨 교단이냐"가 아니라 **"활성이고 정당한 청빙 게시판이냐"**. → 초교파 게시판(§1 끝 소그룹)도 활발하면 **모드 B로 포함**.
>
> ✅ **크롤 대상 확정(2026-07-27 운영자 전수 실측)**: **크롤 31곳 · 제외 6곳.** 제외 = 예장합동총회·백석대신총회·순복음총회신학교·**기장총회(PROK, 2025-08 이후 공고 0)**·에스라·서울성경신대(§4). 로그인 티어(§2 · KMC·AGK·기독신문·CTS)는 법률 게이트 대기라 이 31에 미포함. 최종 목록은 §7.
